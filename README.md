# Expense Tracker App

A simple and intuitive web application to track your daily expenses, visualize spending by category, and view monthly trends.

##  Features

- Add, edit, and delete expenses
- Visualize category-wise distribution with a pie chart
- Analyze monthly spending trends with a bar chart
- Clean and responsive UI

## Tech Stack

- **Frontend**: React, Tailwind CSS, Recharts
- **Backend**: Node.js, Express
- **Database**: MongoDB

## Installation

```bash
git clone https://github.com/Rudrakumarpatel/Expense-Traker.git
cd expense-tracker
npm install
npm start
